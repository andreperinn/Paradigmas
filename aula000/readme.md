## 🧩 Paradigmas

A família de linguagens **Lisp** é essencialmente **multiparadigma**.

Embora tenha nascido historicamente ligada ao **paradigma funcional**, baseada no **cálculo lambda** e no **processamento de listas**, seus principais dialetos modernos, como o **Common Lisp**, incorporam e combinam diferentes formas de programar.

### Principais paradigmas presentes no Common Lisp

* **Programação funcional**
* **Programação imperativa**
* **Programação orientada a objetos**
* **Programação procedural**
* **Metaprogramação**

### 📌 Conceito principal

> **Common Lisp é uma linguagem multiparadigma**, permitindo combinar diferentes estilos de programação de acordo com o problema que está sendo resolvido.
